# mfahsold.github.io

Host root for the GitHub Pages project sites. It provides a `robots.txt` that
points crawlers at the project sitemaps and a small landing page that links to
the maintained projects:

- [Lixity](https://mfahsold.github.io/lixity/) — local manuscript analysis ([source](https://github.com/mfahsold/lixity))
- [Montage AI](https://mfahsold.github.io/montage-ai/) — local-first AI video editing ([source](https://github.com/mfahsold/montage-ai))
- Fluxibri — sovereign inference and application stack (private, in development)

Project documentation and source code live in the respective repositories.
